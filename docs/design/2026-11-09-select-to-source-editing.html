编辑态 = 既有整文档 textarea：IME、undo/redo、粘贴都是原生行为。表格与其他块同机制（无类型分支）：hover 整表淡描边（块级）、点格落该格文本范围（格级）、拖选落整表行区间。Esc 或点「预览」退出源码模式（沿用既有行为）。首次帮助文案只出现一次——
稿外取舍（spec 未规定、由本稿定稿的视觉细节）
  • hover 淡描边 = 1px 黄铜内描边（inset shadow，零 reflow）+ 圆角 8px + cursor: text；不引入按钮、角标或常驻 chrome（spec §2.1）。
  • 首次帮助文案（定稿）：「在预览里点一下、或拖选一个块，直接落到源码的对应行；表格里点一下某个格，就地改这一格」——文档区顶部一行小字，首次落位后淡出、不常驻（spec §2.1：文案由设计稿定稿；格点击是新增手势，文案点出发现性入口）。
  • 落位可见性 = textarea 原生选区高亮（仅把选区色纳入黄铜主题），不加高亮带、不加行号栏（spec §4.2）。
  • frontmatter 卡的手势分区：卡身点击落源码（spec §8.4）；头部折叠手柄沿用既有折叠行为，不触发落位——spec 未规定两者冲突，本稿取「手柄保既有」。
  • 保存后切回预览：真应用保存不强制切模式；本稿保存后切预览以直观展示「重渲染、编辑生效」（spec §6 只规定保存后重渲染）。
