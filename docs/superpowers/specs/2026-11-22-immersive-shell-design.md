# 沉浸式壳重构设计（immersive-shell）

- 日期：2026-11-22（rev2 二修：常驻 rail → 左下悬浮圆钮入口 + 默认单栏态；rev3 三修：AI 面板 → 右缘半隐把手 + 管家气泡栈 + 聊天浮窗，均用户拍板）
- 状态：设计定稿（§2 七项拍板），待用户评审 → 实施计划
- 范围定性：壳级架构重构（导航模型 + 栏位模型 + 操作路径）；同步/索引/agent/设置热生效等底层子系统行为零改动
- 法源与关联：首页 spec §10「沉浸式壳」演进位的兑现（`2026-11-22-home-butler-landing-design.md`，Home 零改动契约必须守住）；设置页 spec（`2026-11-22-settings-page-design.md`，modal 壳复用）；预览稿同目录 `2026-11-22-immersive-shell-preview.html`

## 0. TL;DR

桌面壳从「rail + 二级面板 + 记忆控制台 + 顶栏 + 文档 + AI 面板」收敛为：

**零常驻 chrome 的单栏默认态（文档信笺全宽）＋ 左下悬浮圆钮（hover 右上扇弧展开子页入口）＋ 右缘文档操作图标条（有文档时）＋ 按需左右槽位（栏数 = 1 + 开启槽数 ∈ {1,2,3}）＋ 子页一律左侧悬浮抽屉。记忆控制台并入设置浮窗。**

≤1023px 移动端本次零改动（TopBar/rail 降级为移动专属壳，sheet/drawer 体系照旧；扇弧入口是桌面鼠标语义，不上移动）。

## 1. 背景与目标

**现状**（app.js 根模板实测）：rail(64px) + 二级面板(200px in-flow) / 记忆控制台(300px in-flow) / TopBar(48px) / 文档区 + 关联侧栏(280px) / AI 面板(tab 式) / 监控页整页接管。

**痛点**：① 固定面常占宽度——三面同开时文档列被压到极窄，沉浸感为零；② 文档操作散落三处（顶栏按钮、树「⋯」菜单、移动更多菜单），同一动作多入口互相漂移；③ 整页接管（监控）与 in-flow 面板（记忆）两种重占位模式交错，导航心智负担大。

**目标**：打开任何页面的默认态就是「纸面即全部」；chrome 只在被召唤时出现，用完即零占位；全局入口收拢为一个悬浮圆钮，关闭出口统一为 Esc / 点外。

## 2. 拍板决策（用户 2026-11-22，六题；rev2 修订 #6 并补 #1 细则）

| # | 决策 | 弃用备选 |
|---|---|---|
| 1 | **槽位自由组合 + 默认单栏态**：左槽=文件树、右槽=AI⇄关联（互斥一槽一面）；栏数 = 1 + 开启槽数 ∈ {1,2,3}；**打开文档/进入首页默认 0 槽（单栏）**，槽位开关按设备记忆（localStorage） | 固定栏数档位；默认双栏 |
| 2 | **顶栏桌面端彻底删除**，职责分流（§5） | 极轻顶栏；底部状态栏 |
| 3 | **文档操作 = 右缘常驻图标条（RightDock）+ 直绑快捷键**（§5） | 命令面板为主；hover 才显形的细条 |
| 4 | **子页全部悬浮抽屉**（文件/搜索/回收站/监控）；**记忆控制台并入设置浮窗** | 监控进设置浮窗；监控维持整页接管 |
| 5 | **桌面先行**：≥1024px 用新壳；≤1023px 维持现有 sheet/drawer 体系（rail/TopBar 降级移动专属） | 两端一次到位 |
| 6 | **rev2 · 常驻 rail 退役，入口 = 左下悬浮圆钮（FAB）**：48px 纸色圆钮钉屏幕左下（贴边 24px），glyph「M」；**hover 展开右上 90° 扇弧**六枚子选项钮（文件/搜索/回收站/监控/通知/设置）；点文件/搜索/回收站/监控 → 左侧抽屉滑入；点通知 → 下拉（锚扇区上方）；点设置 → 浮窗；**点圆钮中心 = 回首页 + 清 hash**（首页 spec B1 手法迁移至 FAB 中心）。悬停为主触发，**点击展开与键盘路径（Tab 到 FAB → Enter/方向键 → Esc）为同等后备** | 常驻 rail（初版方案）；左缘环列；左缘半隐纵列（三选一定形于预览交互稿） |
| 7 | **rev3 · AI 面板对话化**：右缘**半隐把手**（现 `#ai-btn` 边缘 tab 升格）＋**管家气泡栈**（悬浮纵向、叠最近摘要消息，聊天应用弹窗式）；点把手 → **聊天窗浮层**，浮层图钉升级右槽常驻；气泡栈=**摘要面**（第一人称短句）、FAB 铃铛=**详情面**（系统台账现状）——两面先分立（用户「先分开吧」），归一进演进位 | 直接占栏（初态）；单一消息面归一（留演进） |

**rev2 动因（用户反馈原话大意）**：三栏态与现状差异感知不足——沉浸的兑现点必须在「默认态零 chrome」与「入口去常驻化」，而不是把满配栏位重新画一遍。

方案比选记录：渐进壳改造（采纳）vs 新建 Shell.js 壳组件重写（边界更干净但 diff/回归面大、与 Home 并行会话冲突强，弃，留演进位）vs 最小两步拆（中间态不沉浸、同模板碰两次，弃）。

## 3. 新壳结构

```
┌────────────────────────────────────────────────┬────┐
│  左槽(文件树 260px, 默认关, in-flow)              │dock│
│  ┌──────────────────────────────────────────┐  │ ~│
│  │  文档头行：路径 · 隐私徽标 · dirty 点        │  │40│
│  │                                          │  │px│
│  │          文档列（max-width 居中）           │  │  │ 右槽（AI ⇄ 关联,
│  │                                          │  │  │ in-flow, 默认关）
│  └──────────────────────────────────────────┘  │  │
└────────────────────────────────────────────────┴────┘
 ◉ 左下悬浮圆钮（hover→右上扇弧：文件 搜索 回收站 监控 通知 设置）
 浮层抽屉（文件/搜索/回收站/监控）= absolute 悬浮覆盖主区，transform 滑入，零挤压
```

- **FAB（唯一常驻全局入口，48px，fixed 左下 24px）**：纸面亮底（`--surface`）+ 细边 + 软投影，glyph「M」（衬线，黄铜色，与 logo-mark 同源）。**聚合徽标点**：回收站数 / 通知未读 / 记忆待审任一 >0 → 圆钮右上 8px 黄铜点（无数字，数字在展开后的子钮徽标上）。hover（迟滞 ~80ms 防误触）→ 六枚 34px 子选项钮沿右上 90° 弧（半径 ~92px）弹性展开；子钮各带图标 + 各自徽标（回收站数、通知未读、记忆待审，口径同现状 rail 徽标）。收起：选中子页 / Esc / 指针离弧区（迟滞 ~250ms）。无障碍：`aria-expanded` + role=menu/menuitem + 方向键沿弧移动。
- **主区**：无当前文档 → Home（首页契约「只占据主区」继续成立，Home 组件零改动）；有文档 → 文档区。
- **文档头行**：文档列顶部一行内联弱色小字——面包屑路径 + 隐私徽标（现状 display-only 口径原样）+ dirty 点。无背景无边框，视觉上不成立「第二条顶栏」。
- **RightDock**：右缘常驻图标条（有文档时），见 §5。
- **槽位**：左槽 = 文件树（~260px）；右槽 = 关联侧栏（现 280px）或 AI 聊天面板（现 `#ai-panel` 宽，**仅经聊天浮窗图钉升级进入**，§4A），二选一互斥。**默认全关（单栏）**；开关状态 localStorage 记忆（`mdvault.shellSlots`，多设备各记各的）。槽位是 in-flow 的（开槽挤压主区——这是「占栏」的定义形态，与浮层抽屉互补共存）。AI 不是 FAB 子页钮，入口 = 右缘半隐把手（§4A）；关联入口在 RightDock（§5）。

## 4. 浮层抽屉（FAB 子页的统一容器）

**容器纪律**：absolute 定位于主区 relative 容器内、左侧滑入；过渡只走 `transform: translateX` + opacity（GPU、零回流）；桌面态**无 backdrop**（点击外部关闭）；同屏至多一个抽屉（开新关旧）。

| 抽屉 | 宽（建议值） | 关闭路径 | 特殊 |
|---|---|---|---|
| 文件 | 320px | 选文档 / Esc / 再点同一子钮或 FAB 收起 / 点外 | 头部图钉钮 → 钉住升级为**左槽常驻**（FAB 文件子钮 on 态 = 钉住）；取消钉住即关 |
| 搜索 | 380px | 选中结果（openDoc）/ Esc / 点外 | 与移动端既有 `#search-drawer` 断点隔离，不共享实例 |
| 回收站 | 360px | Esc / 点外 | 行内还原/清空操作**不自动关**（操作流连续性优先） |
| 监控 | min(920px, calc(100vw − 96px)) | Esc / 点外 / **openDoc 一律关**（替代现「openDoc 退监控页」守卫） | MonitorPage 组件本体零改动，仅换挂载容器 |

**全局规则**：① `openDoc` 一律关闭文件/搜索/监控抽屉（回收站不在 openDoc 路径上，不受影响）；② Esc 链优先级：扇弧展开 > 设置浮窗 > 抽屉 > dock 浮层（目录等）> 其余下拉——现链延伸，不改既有设置浮窗优先级；③ 状态收拢：新增 `drawer: null | 'file' | 'search' | 'trash' | 'monitor'`，桌面端取代 `state.monitoring` / `state.filePanelOpen` 的桌面语义（移动端 flag 路径保留，§10）。

## 4A. AI 消息面（rev3：半隐把手 + 管家气泡栈 + 聊天浮窗）

三件套（全部仅 ≥1024px；移动维持现 sheet 体系）：

- **半隐把手**：现 `#ai-btn` 右缘 tab 的升格——值班态是右缘一条 ~10px 宽竖向待命握把（弱色、absolute 悬浮不占栏），未读数徽标 pill；点击/悬停展开聊天浮窗。把手常驻（Home 态也在——管家总在书房）。
- **管家气泡栈（摘要面）**：悬浮于把手上方，纵向叠最近**摘要消息**（默认 3 条 + 「+N」，第一人称短句 + 弱色时间，例：「收了 3 篇，一处对不上，您看下」）。
  - 内容源（要事优先，非全量流）：① 管家回您的话——agent Run 在浮窗关闭期间完成的未读 assistant 行；② 可行动事件摘要——记忆提案待审 / 同步冲突 / bgagent 失败，**由既有通知数据前端第一人称摘要化渲染，后端零新增**。
  - 点气泡 = 直达落点（文档 / 设置·记忆标签 / 监控抽屉 / 聊天浮窗）。栈的「看过」是独立游标（`mdvault.lastPeekSeq`），与铃铛未读分离——用户「先分开吧」。
  - **与铃铛面边界**：栈只画「需要您搭话的事」一句话；数量分解、状态明细、历史台账全归 FAB 铃铛下拉（现状不改）。同一事件两现 = 摘要 vs 详情的分工（栈是铃铛的口头汇报版），非重复。
- **聊天窗浮层**：~400px 宽 × ~60vh，右缘悬浮停靠（与 dock 顶缘错位避让）；AIChatPanel 组件本体最小改动（换壳 + 关闭钮 + 图钉）。**图钉 → 升级右槽常驻**（与文件抽屉→左槽同一套升级语法），AI 占槽后 §3 右槽互斥规则生效；图钉态并入 `mdvault.shellSlots` 记忆。
- **管家专属图标 = 线性领结**（用户 2026-11-22 拍板，弃用通用四角星 AI 符号）：落点三处——半隐握把中央（纸色细线，值守标识）、聊天浮窗头部（`ai-brand` 位）、气泡栈源头位；实现期进 `utils/icons.js` 单点（新增 `bowtie` 条目，禁多处内联副本）。**FAB 维持「M」字样**——圆钮是整屋入口（品牌资产），不是管家个人头像，两套符号各司其职。
- **流式语义**：Run 流式仍走 RunHub 事件通道，投递/订阅分离铁律（AGENTS 条款）零改动；浮窗打开按现行 cursor/snapshot 语义现场接上，关闭期间不打断、完成后气泡栈出一条摘要。

## 5. 顶栏拆除与 RightDock

**TopBar 职责分流表**：

| 原顶栏元素 | 新落点 |
|---|---|
| logo + 回首页 | FAB 中心（§3，清 hash 手法随迁） |
| 通知铃铛 + 下拉 | FAB 子钮（通知），下拉锚扇区上方展开（复用现下拉 DOM/逻辑，只换锚点） |
| 当前路径 + 隐私徽标 | 文档头行（§3） |
| 编辑⇄预览、保存、下载、目录 | RightDock（目录钮开 `.toc-dd`，锚点改 dock 左缘） |
| 关联 | RightDock 钮（开右槽关联面；右槽被 AI 占据时 = 切面） |
| 「更多」菜单（移动） | 保留——TopBar 整体降级为 `lg:hidden` 移动专属壳 |

**原 rail 去向**：文件/搜索/回收站/监控 → FAB 子钮（§3）；记忆 → 设置浮窗标签（§6）；设置 → FAB 子钮；齿轮徽标 → FAB 设置子钮徽标。

**RightDock（新组件 `RightDock.js`，~40px，仅 ≥1024px 渲染，有文档时常驻）**：
- 钮自上而下：编辑⇄预览（激活态=编辑）· 保存（dirty → 黄铜点）· 下载 · 目录 · 关联 · 重命名 · 移动 · 删除（告警色，两步确认）。
- 禁用规则：docMissing → 钮禁用；无文档时 dock 整条隐藏（Home 态零 chrome）；**按钮恒定渲染零跳变**（现顶栏 D5 口径平移）。
- 处理器复用：mode/save/download/toc/关联 = app.js 现有 handlers 直挂；rename/move/delete = FileTree「⋯」菜单同款（实施注记：处理器上提 app 层或抽 util，形态由实施期按 FileTree 现状定，**不得**在 dock 内另起一份实现——单一写面）。
- **快捷键（本次只两条 + F2）**：`Ctrl+S` 保存；`Ctrl+E` 预览⇄编辑（Chromium 若占键 → 退 `Ctrl+Shift+E`，实施期实测后本表为唯一真源更新）；`F2` 重命名（文档区焦点时）。无命令面板（YAGNI，§12 演进位）。
- 移动端：dock 与 FAB 均 lg-only；≤1023px 用 TopBar「更多」菜单（现状不动）。

## 6. 记忆控制台 → 设置浮窗

- SettingsPage 增加标签页「记忆」：**MemoryConsole 组件本体零改动**，队列/详情/报告三面整体迁入浮窗内容区（宽度自适应容器）。
- 入口：FAB 设置子钮 → 浮窗 → 记忆标签；新增深链 `#memory` = 浮窗 + 记忆标签。报告深链（通知 report_paths → `memoryReport`）落记忆标签报告面。
- 徽标：记忆 badge 上 FAB 设置子钮（badgeParts 需人参与总和，title 分解构成，口径同原 rail 记忆钮）。
- 守卫边界：设置 dirty 守卫只管 config 表单 dirty；提案裁决/报告浏览**不进** dirty；`settingsCloseSeq` 关闭链零改动。设置热生效全链（PUT 预检 / agent_cache 代际 / supervisor apply 契约）零接触。
- 状态：`memoryOpen` 与 `console-shell` 退役；`memoryDetail`/`memoryReport` 归记忆标签上下文；`pollMemory` 轮询保留（徽标数据源）。

## 7. 布局与动效纪律（对既有坑红线的显式映射）

- 抽屉过渡只走 `transform`，**绝不动 width/flex-basis**（AGENTS 坑清单）；槽位开合是一次性宽度变化（非逐帧动画），可接受——文档列 max-width 居中于剩余空间，无逐帧居中需求；「absolute 面板不参与 flex 布局」坑对抽屉是**特性不是缺陷**（零挤压即设计目标）。
- **扇弧 hover 契约**：FAB 与子钮之间用不可见扇区桥（clip-path 锥形或透明三角）承接指针——指针从圆心移向任一子钮不得中途收起；收起只认「指针离桥区 250ms / 选中 / Esc」。hover 展开延迟 ~80ms 防路过误触。`prefers-reduced-motion`：扇弧降级直切显隐（位移不弹跳）。
- 隐藏容器 `clientHeight === 0` 坑：FileTree 在抽屉内的滚动定位（revealActive/expandToPath）沿用既有 pending-flag + ResizeObserver 纪律，实施期核对既有先例可达。
- z-index 层序（自下而上）：dock(10) < FAB(20) < 抽屉(30) < 通知下拉/目录浮层(50) < 扇弧子钮(55，压过同屏抽屉) < 设置浮窗（既有层）。
- 键盘/视口红线：`focus({preventScroll:true})` 口径不因新浮层破例；壳高仍走 `html,body,#app{height:100%}` 链（回归钉 `test_shell_uses_layout_viewport_height` 不破）；skip-link 指向不变。

## 8. Home 契约与并行会话协调

- Home 契约：主区存在性保留，Home 组件零改动（首页 spec「壳怎么变 Home 不动」兑现）。
- 「点左上字样回首页 + 清 hash」→「点 FAB 中心回首页 + 清 hash」：行为回归钉从顶栏版换锚到 FAB 中心，语义逐字保留（首页 spec B1）。首页 §4.4 页脚文案「点左上角字样」届时随文案常量改「点左下角圆钮」——**归 Home 会话改**，本壳侧登记接口事实即可。
- **排期红线**：本 spec 只定稿；实施必须等 Home 实施会话（正在按首页 spec 施工）**合入后**启动——两件事都碰 app.js 根模板与 style.css，双开必冲突。

## 9. 安全红线对照（2026-11-18 八条）
