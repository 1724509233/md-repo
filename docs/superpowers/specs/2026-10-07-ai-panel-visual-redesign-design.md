# AI 面板视觉重设计（轻量降噪）

日期：2026-10-07  
范围：仅 `server/templates/index.html` 与 `server/templates/style.css` 中的 AI 面板  
目标：降低视觉噪音、优化信息层级，使 AI 面板在长时间使用中更舒适、更专注。

## 背景

md-vault Web UI 采用纸墨风（暖纸白 + 深墨 + 黄铜强调色）。现有 AI 面板功能完整，但视觉元素偏多：边框、阴影、高饱和状态色、动效时长偏长，长时间使用时容易分散注意力。本次重设计不改变功能与布局结构，只优化视觉与交互细节。

## 设计原则

- 保留现有纸墨风与黄铜强调色。
- 用间距、字号、字重建立层级，减少边框和阴影。
- 状态色只在必要时出现，默认使用灰墨色。
- 动效短、克制，且尊重 `prefers-reduced-motion`。
- 输入框支持多行自动扩展，但不挤压面板其他区域。

## 具体改动

### 1. 视觉层级

- 面板背景保持 `--surface`。
- 头部与输入区用 1px `--line` 分隔，消息区不再使用额外卡片边框。
- 用户消息气泡：低饱和黄铜色背景（`color-mix(in srgb, var(--brass) 12%, transparent)`），文字用 `--ink`。
- AI 消息气泡：`--surface` 背景 + 1px `--line` 边框，文字用 `--ink`。
- 工具调用摘要行默认使用 `--ink-soft`，状态图标仅在 `done` / `confirm` / `error` 时着色。

### 2. 间距与密度

- 消息列表间距从 `space-y-3` 调整为 `space-y-4`。
- 工具调用详情默认折叠；摘要行高度压缩，参数使用等宽字体小字。
- 输入区 padding 收紧，textarea 与发送/停止按钮垂直对齐更紧凑。

### 3. 动效

- AI 面板滑入/滑出保留 `transform`，时长从 `.35s` 缩短到 `.25s`。
- 消息入场动画从 `.25s` 缩短到 `.15s`。
- `prefers-reduced-motion: reduce` 时禁用消息入场与面板滑动动画。
- 流式光标闪烁保留，颜色从 `--brass` 改为 `--ink-soft`。

### 4. 状态提示

- “思考中”三点动画保留，字号缩小，颜色使用 `--ink-soft`。
- Token 用量条默认隐藏；仅在 hover 或 token 占比超过 50% 时显示。
- 错误状态使用文字 + 图标，不使用红色背景块。

### 5. 输入框自动扩展

- 输入 textarea 在文本换行后自动增加高度。
- 最大高度限制为 AI 面板高度的 40%。
- 达到最大高度后 textarea 内部滚动，不改变面板整体布局。
- 发送消息或清空输入后高度复位到单行。

### 6. 可访问性

- 焦点环保留黄铜色，宽度从 4px 减到 2px。
- 所有交互元素保持键盘可达。
- Tab 顺序：头部按钮 → 消息区（只读）→ 输入框 → 发送/停止。

## 不在范围内

- 不改变 AI 面板的桌面侧滑 / 移动底部抽屉结构。
- 不调整全局设计 token（颜色、字体、间距变量）。
- 不新增命令面板、暗色模式、自动保存等功能。
- 不修改后端 API 或 SSE 事件协议。

## 验收标准

- AI 面板在桌面和移动端均保持现有开合行为。
- 消息区视觉噪音降低，重点信息（状态、消息、工具调用）更清晰。
- 输入框可随内容增高，最大不超过面板高度 40%，且不挤压头部、消息区、token 状态区。
- `prefers-reduced-motion` 开启时无面板滑动和消息入场动画。
- 焦点环可见且宽度为 2px。
