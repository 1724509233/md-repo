决策清单 D1–D6（可拍板）

D1 放置　推荐 a
a 顶栏「目录」按钮+浮层（本稿）· b 文档区内可折叠左 rail · c 预览顶部内联折叠块。
理由：顶栏方案零常驻宽度——内容列本就 680px 居中，rail 会把它挤成更窄且需重新算居中/滚动锚点（正是面板抽屉清单要防的 reflow 坑）；AI 抽屉打开后内容 ≈50%，rail+列 在 1024px 视口下连 300px 都不剩，rail 在该场景不成立；内联块只在预览态存在、吃掉正文首屏垂直空间、随文档滚走（入口消失）。浮层是唯一同时满足「两态可用 / AI 窄态可用 / 移动窄宽可用」的形态。按钮位置恒定（不随有无标题显隐）→ 顶栏布局零跳变。z-index 50 与通知下拉/更多菜单同层，向下展开不遮挡工具条本体。

D2 内容与层级　推荐：渲染 DOM 为真值
从 #preview h1–h3 取（而非正则扫原始 markdown）：① 与渲染真值一致——代码块内的 # 注释、引用块渲染差异等正则误判全部免疫；② 编辑/预览两态共用同一份——#preview 是 v-show 隐藏而非移除，textarea 每敲一字 computed 重渲染，DOM 永远同步；③ 顺带把标题 id 注册表建在渲染期（D3/D6），跳转与编辑跳行共用。h1–h3 三级缩进（0/14/28px），h4+ 忽略（路线端口径）。标题超长截断 + tooltip 全文。

D3 跳转策略　推荐：预览平滑滚动 + 编辑光标跳行（两态都可用）
预览：渲染期给每个标题写 sec-N id → scrollIntoView 到滚动容器（文档区 .overflow-y-auto），block:'start' + scroll-margin-top:16px；prefers-reduced-motion 时退化为 auto（app.js 已有 reducedMotion() 助手）。落点复用现有 .heading-flash 闪光（与深链跳转同一视觉语言，零新 CSS）。编辑：不隐藏 TOC——点条目 = 选中原始 markdown 中该标题整行（selectionStart/End）+ scrollTop = 行号 × 24.5px − 48（行高 = 14px×1.75 恒定，像素精确）；编辑器无逐行高亮能力，选中行本身就是反馈，不加假闪光。行号在渲染期由 marked renderer.heading 的 raw 参数定位（源串 indexOf 游标），与 id 同张注册表。

D4 当前节高亮　推荐：做（轻量版）
成本：~40 行。仅浮层开启期间挂滚动监听（rAF 节流，关闭即解绑 = 常态零开销）；当前节 = 最后一个「顶边越过容器顶 +96px」的标题；活跃条目黄铜高亮 + 加粗，列表内部溢出时自动保持可见。收益：AI 抽屉打开（内容列减半、滚动翻倍）正是最容易「我在哪」的场景，而浮层是悬浮的——开着浮层滚文档时高亮持续有效。编辑态不做（textarea 滚动位置无章节语义）。可延后，但基础设施（id 注册表 + 条目 DOM）本轮已就位，后补零成本。

D5 空态　推荐：按钮恒显，浮层显示空态行
无 h1–h3 时：按钮不隐藏（隐藏 = 用户编辑删掉最后一个标题时顶栏布局跳动，且「入口哪去了」不可发现）；也不禁用（禁用按钮点击无回应 = 假死感）。点击照常开浮层，列表区显示一行「本文档没有标题」（12px ink-soft 居中）。按钮上不挂标题计数（实现 meta，违反文案规范）。

D6 slug 与中文　推荐：序号型 sec-N（机器私有命名空间）
中文原文 slug 要处理引号/表情/标点转义（heading 里啥都有），拼音要引无构建 CDN 依赖——都不值。序号型 sec-1…sec-N：① 零 Unicode 边界、绝对唯一（渲染计数器）；② 前缀 sec- 是机器私有空间，用户手写的 #anchor 走的是另一条通道（data-vault-anchor 文本匹配，根本不产生 DOM id）→ 结构性不冲突；③ id 每次渲染重建，TOC 条目与 id 出自同一次渲染 → 无悬空引用。代价：id 不可读——无所谓，SPA 无 URL 栏、无分享链接（若未来要深链 URL，届时升级为 GitHub 式 CJK slug，注册表设计不受影响）。TOC 点击走 id 定位；跨文档深链（app.js L131）保留文本匹配兜底，实现轮抽成同一个 scrollToHeading 工具供两处复用。

浮层五项清单（panel/drawer 规范）

  • 放置顶栏右端之下 absolute; right:8px; top:calc(100%+8px)，锚定内容区右缘（AI 窄态下顶栏已收缩，浮层自然收进内容区）；宽 260px，移动 min(260px,100vw−48px)
  • 过渡opacity + translateY(4px→0) + scale(.98→1)，140ms，transform 路径零 reflow，origin 顶栏（与通知下拉语言一致）；关闭 = 反向 140ms 后收起
  • Reflow零：浮层不参与 flex 布局，开关不改任何内容区尺寸/居中；文档滚动位置在开关浮层时不动
  • 开关两态可见同一顶栏按钮：关闭态 ghost，开启态黄铜 12% 底 + 黄铜图标（只变色不变几何，位置不跳）；Esc / 点击外部关闭（委托，同更多菜单模式）
  • Z-index50 = 通知下拉/更多菜单同层；ai 面板 15 / ai-btn 25 之下层级链不动；向下展开不遮工具条本体；移动端边缘：AI 底部抽屉（z-40 + backdrop z-30）打开时 TOC 浮层会被盖在 backdrop 之上露出残影 → 开 AI 抽屉时同步 tocOpen=false
