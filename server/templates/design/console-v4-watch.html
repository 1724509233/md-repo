后台页 · 非对称网格 · 入口/出口与零态规则
  • 独立页面而非面板子面——通知槽位契约拆两问：「系统需不需要我」（面板）/「系统健康吗」（本页）。面板 300px 是行动面，监控是 1200px 非对称网格阅读面（两组两问；≥1024px 网格、≤1023px 回单列），两者要不同宽度与节奏。与通知面板互斥：入口 = L0 行尾「后台 →」（点击 = 面板收起、本页接管主区域）；出口唯一 =「← 返回文档」（生产：回文档视图，面板不自动重开，重入走 rail【通知】）。
  • 非对称网格（用户 2026-10-23 选定，来源 layouts 稿 02E）——row-major ①∣② / ③∣④ / ⑤ / ⑥ = 区块锁定顺序，零重排（DOM = ①②③④⑤⑥ 自然落位）；组标题行通栏（两问叙事不丢）；⑤ 召回、⑥ 最近终态通栏；列比 1:1.6（② trail 长路径与④大数字需宽，①③放窄列）；行内等高（stretch），④ 内容少 → exec-vis 垂直居中，① 顶部对齐。≤1023px 回单列 = 同样零重排（= 场景 04 的窄屏回退形态）。六网格单元永远在场：网格模板不因数据增删变形、不 reflow；计数 = 0 → 卡内容 = 淡显占位（.zline）。⑤⑥ 通栏 → L2 表格横向滚动需求下降（overflow-x 仅留 200 行生产数据兜底）。
  • 内芯 = D 图形内芯（与 02D/02E 同源，命名/取值完全一致）——后台任务 = 分段刻度条（实心段 = 当前 arm，总段数 = 目标）、执行器 = 大数字 + armed 状态灯（脉冲 = 在跑）、召回 = top5 比例条（宽度 ∝ w 值，最大 86.0 归一，值标条尾兜底）、异常清单 = 红边卡、最近终态 = 文字行（终态 = 事件非比例，不图形化）。30s 轮询 = 快照，无时序数据：刻度条 / 比例条静态，不画动画填充、不画趋势曲线（轮询间隔 30s 的「增长」是假象，趋势图会误导「在改善/在恶化」）。
  • 零态 = 常驻淡显一行——六区块全部常驻；计数为 0 时只渲染一行淡显占位（无异常 / 无终态 / 无召回流量），不隐藏区块——健康页的访问目的 = 来确认「没问题」，空态必须可见地给出答案。演示数据六区块均非零，故稿中不实例化 .zline；生产按此渲染（CSS 注释已写明）。
  • 数据口径 = 轮询缓存——六个区块全部来自 30s 轮询的 /api/memory/status + /api/memory/proposals，后端成本为零；armed_target / runs_cap 端点恒 null，目标值标「取自 config」。唯一按需层 = L2（点召回卡按钮触发一次 GET /api/recall/stats，docs / failed_queries 各 cap 200 行）。
  • 素材复用——后台任务 = 稿 B 脉列 / 稿 A 账本行 02（trigger_state 两行原字段）；执行器 = 两稿的 30min 虚线行展开成区块；召回 = 稿 A 行 04 / 稿 B 召回榜（top5 + last_hit）；最近终态 = 稿 B「最近终审」扩到 failed；异常清单新增（trail 按需取，/proposals/{relpath}/trail，本轮从系统组移入状态组）。
  • L2 = 全页唯一按需层，卡片内独立按钮——0fr→1fr 靠 grid-template-rows + overflow 裁剪（复用稿 A 模式），不用 opacity → 不产生 a11y 隐面；.rcl-l2btn 走通用 button[aria-controls] 接线（rcl-toggle-s2 → fold-l2-s2），aria-expanded 与折叠同步；prefers-reduced-motion 下展开 / 脉冲 / 车标全静止；mtable 表自身横滚（通栏后需求下降）。演示各放 7 / 3 行。

交互契约（本轮对齐）
  • 入口 = L0 行尾「后台 →」——监控 = 通知总揽的详情，与终审详情「单条 → 子页」分层：总览 → 主页 / 单条 → 子页（面板是总揽，监控页是它的主页；详情是单条的子页）。rail = 纯面板选择器（【后台】槽不存在，页面身份 = topbar 文件槽）。
  • 互斥 + 单出口——面板与监控页互斥：点击入口 = 面板收起、监控页接管主区域；出口唯一「← 返回文档」回文档视图，面板不自动重开（重入走 rail【通知】）。

  • 零态常驻淡显——六区块全部常驻，计数 = 0 时只渲染一行淡显（无异常 / 无终态 / 无召回流量）：健康页的访问目的 = 来确认「没问题」，空态必须可见地给出答案。
